The name "RAM Doctor", the logo and the project's visual identity belong to
7san. The [LICENSE](LICENSE) does not grant any right to them.

You may:

* say that your own, separately named work is "compatible with RAM Doctor", as
  long as it is clear that it is not the official project.

You may not, without written permission:

* use "RAM Doctor", "RAM Doctor Pro" or the logo as the name of a modified,
  re-packaged or different program, or in any way that suggests it is the
  official release;
* use this project's website, release links or repository to distribute other
  builds;
* present another build as signed, verified or endorsed by the project.

Official downloads come only from
[github.com/iiKurro/ram-doctor/releases](https://github.com/iiKurro/ram-doctor/releases);
check the file against `SHA256SUMS.txt`.

Found a copy that impersonates the project, or one that contains malware? Report
it privately through [SECURITY.md](SECURITY.md).
